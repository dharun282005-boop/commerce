## Caveat

The fixture pairs come from data written for this project, and the matcher was developed alongside them. The held-out set (60 hand-written pairs, titles only) was meant as the fairer test, but the title rules (variant words, model codes, unit normalisation) were added **after** a first run on it. First run on 2026-10-29: held-out precision 0.714, recall 0.577 (6 false merges, e.g. iPhone 16 Pro vs Pro Max). So these held-out numbers are optimistic. A new, unseen set of real titles is needed for an honest number (listed in docs/15).
